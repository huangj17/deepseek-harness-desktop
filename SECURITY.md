# Security Policy

## Supported versions

Security fixes are applied to the latest desktop release.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability that could put users or credentials at risk.

Use GitHub's private vulnerability reporting feature for this repository. Include:

- the affected desktop and Harness versions;
- reproduction steps;
- expected and observed behavior;
- the potential impact; and
- any suggested mitigation.

Do not include real API keys, private logs, or user data in a report. Replace sensitive values with test data.

For vulnerabilities in DeepSeek Harness itself rather than this Electron wrapper, report them through the official DeepSeek Harness project.
